# WinSetup Lite

**AI 辅助的 Windows 11 装机助手**

WinSetup Lite 将软件选择、安装状态检查和装机清单保存集中在一个桌面窗口。重装系统或换电脑后，用户可以导入以前保存的清单，只安装这台电脑缺少的软件。第一次整理清单时，也可以用中文描述电脑的用途，让本地大模型生成一份可编辑的草稿。

> **项目状态**　目前处于选题与设计阶段，下文描述第一版计划功能。

## 使用示例

假设你换了一台电脑，准备恢复 Python 开发环境。你可以手动勾选软件，也可以输入「这台电脑主要用来写 Python，需要 Git，沿用已装的 VS Code，暂时不装新的浏览器。」

程序计划根据内置软件目录生成候选清单，再检查每项在本机的安装状态。以下是示例结果。

| 软件 | 用途 | 检查结果 | 确认后的操作 |
| --- | --- | --- | --- |
| Python | 运行 Python 项目 | 未检测到安装 | 安装 |
| Git | 版本管理和仓库操作 | 未检测到安装 | 安装 |
| Visual Studio Code | 沿用现有编辑器 | 已安装 | 跳过 |

用户可以修改清单，再确认安装缺少的项目。程序会分别显示各项安装结果，清单也可以保存并在另一台 Windows 电脑上重新导入。

## 第一版计划

| 功能 | 计划范围 |
| --- | --- |
| 软件选择 | 内置 3～5 款常用软件，支持手动勾选 |
| 安装状态与执行 | 检查已安装项，确认后通过 WinGet 逐项安装，显示成功、跳过或失败 |
| 清单复用 | 将选中的软件保存为本地 JSON 文件，导入时重新检查当前电脑 |
| AI 生成清单 | 理解用户描述的用途和限制，从内置目录建议软件，并将候选项填入可编辑的清单 |

## AI 如何参与

项目计划通过 Ollama 调用本地 Qwen3 模型。模型读取用户的需求和内置软件目录，以结构化 JSON 返回候选软件 ID 和推荐理由。程序核对这些 ID，在界面上展示有效选项并检查安装状态。用户确认后，程序按预设的软件包 ID 调用 WinGet。

手动勾选、安装和清单导入导出可以独立使用。用户可以按需接入 Ollama，启用自然语言生成清单。 [Ollama 结构化输出文档](https://docs.ollama.com/capabilities/structured-outputs) · [Qwen3 模型页](https://ollama.com/library/qwen3)

## 开发与验证

1. **跑通手动安装。** 使用 Python 和 Tkinter 搭建桌面界面，优先验证已安装项正确跳过、安装失败时有明确提示。
2. **实现清单导入导出。** 检查保存的清单能否重新导入，以及在不同安装状态的电脑上能否更新待装项。
3. **接入本地模型。** 用「只装 Git」「沿用已有编辑器」等输入检查候选项是否符合约束，用户是否能在执行前修改清单。
4. **发布试用版本。** 完善运行说明和测试示例，计划通过 GitHub Releases 提供 Windows 可执行文件。
